Initial Windows x64 release of VoiceTrigger: local voice triggers, ChatGPT desktop dictation and a native desktop interface.

## Downloads

- **VoiceTrigger-v0.1.0-windows-x86_64.zip**: recommended portable package with the executable, instructions, documentation and license notices.
- **voice-trigger.exe**: standalone executable for updating an existing installation.
- **SHA256SUMS.txt**: checksums for the executable and portable ZIP.

Extract the ZIP and run `voice-trigger.exe`. Existing settings remain in `%APPDATA%\VoiceTrigger`; saved custom trigger phrases are preserved.

## Features

- Local Windows SAPI recognition with configurable trigger phrases. New configurations use **Ok GPT**.
- Start a new ChatGPT conversation and dictation; speech followed by three seconds of silence confirms and sends the transcription when the installed app exposes the required controls.
- Open ChatGPT, open an HTTP(S) address or launch a configured executable.
- Native Triggers, Settings, Diagnostics and Credits pages, menus, keyboard shortcuts and resizable layouts.
- In-memory recognition diagnostics and separate system checks, with frequent telemetry limited to the visible Activity view.
- Safe handling of empty SAPI phrase/text results, including the previously reproduced native crash.

## Requirements

Windows 10/11 x64, a working default microphone and an installed SAPI recognizer for the selected language. The initial recognition language is French (France). The executable uses Microsoft's x64 Visual C++ v14 runtime; see the [official supported runtime downloads](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).

ChatGPT dictation requires the signed-in ChatGPT desktop app, its microphone permission and compatible accessible controls. No API key is required. ChatGPT processes dictation under its own services and settings.

## Verification and limits

The publication build uses compiler-path remapping and passes 16 ordinary tests plus the isolated native UI test, including brief real microphone Start/Stop. The executable is checked as Windows x64; archive contents, license notices and SHA-256 sums are verified. Current-machine build paths and personal settings are excluded from the assets.

Native page rendering, minimum-size layouts and simulated 125%/150% scaling were reviewed. Real multi-monitor scaling and screen-reader operation remain unverified. ChatGPT accessibility can change between app versions; a complete new dictation/submission and the long SAPI soak were not repeated for this release. See the included troubleshooting and integration guides.
