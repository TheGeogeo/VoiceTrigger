VoiceTrigger 0.2.0 redesigns the native desktop interface as a single, uncluttered window and adds a dark theme.

## Downloads

- **VoiceTrigger-v0.2.0-windows-x86_64.zip**: recommended portable package with the executable, instructions, documentation and license notices.
- **voice-trigger.exe**: standalone executable for updating an existing installation.
- **SHA256SUMS.txt**: checksums for the executable and portable ZIP.

Extract the ZIP and run `voice-trigger.exe`. Existing settings remain in `%APPDATA%\VoiceTrigger`; saved custom trigger phrases are preserved and open in the light theme.

## Changes

- **Unified window.** The white File/View/Help menu bar is removed and the title bar takes the theme's colors, so the window reads as one surface. Page navigation, Start/Stop, saving and hiding remain available on every page; documentation and source links are on Credits.
- **Light and Dark themes.** **Settings > Appearance** switches the whole window, including the title bar and scroll bars. The choice applies and is saved immediately, without writing other pending edits.
- **Content that fits the window.** One layout plan now positions and paints every page. The content stays inside the window from the 960 × 600 minimum to maximized, the minimum is reduced on smaller monitor work areas, and documentation screenshots no longer include the invisible window border.
- **Consistent controls.** Fields, selects, lists, buttons, segmented tabs, the Live debug switch and the microphone meter share one visual style, with hover and keyboard-focus feedback. Settings are organized as labeled rows in Appearance, Recognition and ChatGPT sections.
- **Fixes.** The recognition-language select no longer looks disabled, the license text reflows instead of breaking mid-sentence, restoring a maximized window from the notification area keeps it maximized, and the window, taskbar and notification area use a dedicated application icon instead of the generic one.
- **Keyboard.** **Ctrl+Q** quits; Ctrl+1–4, Ctrl+S and F1 are unchanged.

Speech recognition, trigger actions, ChatGPT dictation and the three-second silence submission are unchanged.

## Requirements

Windows 10/11 x64, a working default microphone and an installed SAPI recognizer for the selected language. The executable uses Microsoft's x64 Visual C++ v14 runtime; see the [official supported runtime downloads](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist). Custom title-bar colors require Windows 11; earlier versions keep the standard title bar.

ChatGPT dictation requires the signed-in ChatGPT desktop app, its microphone permission and compatible accessible controls. No API key is required.

## Verification and limits

The packaging script builds with compiler-path remapping and runs the ordinary tests, including layout fit/overlap checks for every page, and the isolated native UI test, which covers theme persistence, the shared controls, a brief real microphone Start/Stop and rendering in both themes. Every page was reviewed in both themes at the minimum, default and a large size, and with simulated 125%/150% scaling.

Real multi-monitor scaling, Windows 10 rendering, screen-reader operation and physical hover/focus interaction were not verified. The long SAPI soak and a complete ChatGPT dictation/submission were not repeated for this interface release.
